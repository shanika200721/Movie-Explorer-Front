# Movie Explorer Frontend

Frontend app for searching and exploring movies.

## Setup

1. Install dependencies:

	```bash
	npm install
	```

2. Copy `.env.example` to `.env`. Set `REACT_APP_API_URL` to the backend URL. For local development, use `http://localhost:4000`.
3. Start the app:

	```bash
	npm start
	```

The app runs at `http://localhost:3000` by default.

## Build

```bash
npm run build
```
